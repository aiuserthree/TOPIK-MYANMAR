# 예외 응시자 접수 기능 안내

**적용 대상:** 제110회부터 · **작성일:** 2026-08-19 · **적용 화면:** 관리자 화면 → 접수자 목록

---

## 1. 요청하신 내용과 반영 결과

| 요청 | 반영 |
| --- | --- |
| 접수 기간·마감 중 토픽 Ⅰ·Ⅱ 혼동 응시자를, 제한 인원이 비었을 때 관리자가 수정 | **급수 정정** 기능 추가 |
| 응시자가 정보 수정 중 '취소'를 잘못 눌러 마감 후 재신청이 막힌 경우 '접수'로 되돌리기 | **접수 복원** 기능 추가 |
| 한국 교민 자녀 특별 관리 — 마감 이후 지정 접수 | **지정 접수** 기능 추가 |

세 기능 모두 **접수 마감 이후에도 처리**됩니다. 대신 정원은 평소와 똑같이 지키며, 처리할 때마다 **사유 입력이 필수**이고 누가·언제·무엇을·왜 처리했는지가 「처리 이력」에 자동으로 남습니다.

---

## 2. 급수 정정 — 토픽 Ⅰ·Ⅱ를 혼동해 접수한 경우

**이렇게 하세요**

1. 접수자 목록에서 응시자 이름을 클릭합니다.
2. 왼쪽 **「예외 처리」** 칸의 **「급수 정정」** 버튼을 누릅니다.
3. 바뀔 급수와 **남은 자리**가 함께 표시됩니다. 사유를 적고 정정합니다.

**알아두실 점**

- 옮겨 갈 급수에 **자리가 남아 있을 때만** 처리됩니다. 자리가 없으면 버튼이 잠기고 "정원이 가득 찼습니다"라고 안내합니다. (지금 쓰던 자리는 옮기는 즉시 비므로, 가려는 급수만 비어 있으면 됩니다.)
- 정정하면 **접수번호가 다시 매겨집니다.** (예: `APP-21-1` → `APP-21-2`)
- 응시료가 서로 다른데 이미 수납이 끝났다면 **차액 안내가 표시**됩니다. 차액 정산은 자동으로 되지 않으니 현장에서 처리해 주세요.

**정정할 수 없는 경우**

| 상황 | 어떻게 하나요 |
| --- | --- |
| 수험번호가 이미 부여됨 | 수험번호에 급수 구분이 들어 있어 번호가 어긋납니다. **수험번호 부여 전에** 정정해 주세요. |
| 토픽 Ⅰ·Ⅱ를 함께 접수한 응시자 | 옮겨 갈 급수를 본인이 이미 쓰고 있습니다. 잘못 접수한 쪽을 **취소**해 주세요. |
| 취소된 접수 | 아래 **접수 복원**을 먼저 하세요. |
| 삭제(휴지통)된 접수 | 휴지통에서 **복구** 후 처리하세요. |

---

## 3. 접수 복원 — 응시자가 '취소'를 잘못 누른 경우

**이렇게 하세요**

1. 접수자 목록에서 상태가 **취소**인 줄을 찾습니다. (상단 「취소」 버튼으로 걸러 보면 편합니다.)
2. 맨 오른쪽 **「접수 복원」** 버튼을 누릅니다. (응시자 상세 화면의 「예외 처리」 칸에서도 됩니다.)
3. 사유를 적고 복원합니다.

**알아두실 점**

- **취소하기 직전 단계 그대로** 되돌아갑니다. 사진 심사가 끝나 수납을 기다리던 상태였다면 그 상태로 복원되고, 응시자는 마이페이지에서 이어서 진행합니다.
- 취소할 때 자리가 반납되었으므로 **복원할 자리가 남아 있어야 합니다.** 그 사이 정원이 찼다면 복원할 수 없습니다.

---

## 4. 지정 접수 — 한국 교민 자녀 등 특별 관리

**이렇게 하세요**

1. 화면 오른쪽 위에서 **회차를 선택**합니다. (접수가 마감된 회차도 선택할 수 있습니다.)
2. 접수자 목록 위쪽 **「지정 접수」** 버튼을 누릅니다.
3. **이름·이메일·연락처로 회원을 검색**해 선택합니다.
4. 시험장 · 응시 급수 · 사유를 입력하고 등록합니다.

**알아두실 점**

- 대상은 **홈페이지 회원가입이 완료된 분**이어야 합니다. 증명사진·이름·생년월일 등이 연명부에 그대로 들어가기 때문입니다.
  - 가입이 덜 된 분은 검색 결과에 나오지 않습니다. **먼저 가입을 마치도록 안내**한 뒤 등록해 주세요.
  - 정지·탈퇴 회원도 등록할 수 없습니다.
- 같은 회차에 이미 접수가 있다면 **같은 시험장**이어야 합니다. (오전 Ⅰ·오후 Ⅱ가 다른 캠퍼스로 갈리면 응시자가 이동해야 하므로)
- 등록 후에는 **일반 접수와 똑같이** 사진 심사 → 수납 → 승인 → 수험번호 순서로 진행됩니다.
- 급수 옆에 회차·시험장 **남은 자리**가 표시됩니다. 자리가 없으면 등록되지 않습니다.
- **정원을 넘겨 등록**해야 할 때는 「정원이 가득 찼어도 등록」을 선택합니다. **최고관리자만** 쓸 수 있고, 이력에 「정원 초과 지정」으로 남습니다.

---

## 5. 특별 관리 대상 확인하기

- 접수자 목록 위쪽 **「지정 접수」** 를 누르면 **지정 접수한 분들만** 모아 볼 수 있습니다. 특별 관리 명단은 여기서 확인하세요.
- 명단의 상태 옆에 **「지정」** 표시가 붙습니다. **나중에 급수를 정정해도 이 표시는 사라지지 않습니다.**
- **「예외 처리」** 를 누르면 급수 정정·접수 복원·지정 접수 세 가지를 모두 모아 봅니다.
- 응시자 상세 화면의 「예외 처리」 칸에서 최근 처리 내용과 사유를, 「처리 이력」 탭에서 이전 처리까지 확인할 수 있습니다.

---

## 6. 권한 설정

- 세 기능 모두 **기본은 최고관리자만** 사용할 수 있습니다.
- 일반관리자에게도 맡기시려면: **관리자 권한 → 접수자 목록 → 「예외처리」** 를 체크해 주세요.
- 조회 전용 계정은 사용할 수 없습니다.
- 「정원이 가득 찼어도 등록」은 권한을 주더라도 **최고관리자 전용**입니다.

---

## 7. 운영 시 주의사항

1. **급수 정정은 수험번호 부여 전에** 해 주세요. 부여 후에는 번호 체계가 어긋나 정정할 수 없습니다.
2. **응시료 차액은 자동 정산되지 않습니다.** 화면 안내를 확인하고 현장에서 처리해 주세요.
3. **휴지통 주의** — 접수를 삭제한 뒤 같은 분·같은 급수를 지정 접수로 다시 넣으면, 휴지통에 있던 건은 복구할 수 없습니다(같은 급수가 두 건이 되므로 자동 차단). 남길 한 건을 정한 뒤 처리해 주세요.
4. 모든 예외 처리는 **사유가 필수**이며 그대로 이력에 남습니다. 나중에 확인할 수 있도록 구체적으로 적어 주세요.
   - 예) `응시자 요청 — 토픽 Ⅰ·Ⅱ 혼동 접수 정정 (전화 확인 2026-08-19)`
   - 예) `한국 교민 자녀 특별 관리 — 대사관 협조 공문 접수(2026-08-19)`

---

## 8. 참고 — 안내 메일은 나가지 않습니다

세 기능 모두 응시자에게 **별도 메일을 보내지 않습니다.** 기존 접수·취소와 같은 방식이며, 응시자는 마이페이지에서 변경된 내용을 확인합니다. 메일 안내가 필요하시면 알려 주세요.
