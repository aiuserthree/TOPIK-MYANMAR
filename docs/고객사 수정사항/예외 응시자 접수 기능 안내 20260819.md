# [TOPIK Myanmar] 예외 응시자 접수 기능 반영 완료 안내 (제110회 적용)

> 고객사 발송용 메일 원문 · 발송일 2026-08-19 · 반영 커밋 `f927ba7`

---

안녕하십니까.

요청하신 예외 응시자 접수 기능 개발을 완료하여 오늘 운영 시스템에 반영하였습니다. 제110회부터 사용하실 수 있으며, 아래와 같이 안내드립니다.

## 1. 요청 사항과 반영 내용

| 요청하신 내용 | 반영 |
| --- | --- |
| 접수 기간·마감 중 토픽 Ⅰ·Ⅱ를 혼동한 응시자를, 제한 인원이 비었을 때 관리자가 수정 | **급수 정정** 기능 추가 |
| 응시자가 정보 수정 중 '취소'를 잘못 눌러 마감 후 재신청이 막힌 경우 '접수'로 되돌리기 | **접수 복원** 기능 추가 |
| 한국 교민 자녀 특별 관리 — 마감 이후 지정 접수 | **지정 접수** 기능 추가 |

세 기능 모두 **관리자 화면 → 접수자 목록**에서 사용하시며, **접수가 마감된 뒤에도 처리**됩니다. 처리할 때마다 사유 입력이 필수이고, 누가·언제·무엇을·왜 처리했는지가 「처리 이력」에 자동으로 남습니다.

## 2. 급수 정정 — 토픽 Ⅰ·Ⅱ를 혼동해 접수한 경우

**사용 방법**

1. 접수자 목록에서 응시자 **이름을 클릭**합니다.
2. 왼쪽 「예외 처리」 칸에서 **「급수 정정」**을 누릅니다.
3. 바뀔 급수와 **남은 자리**를 확인하고, 사유를 입력한 뒤 정정합니다.

**참고 사항**

- 옮겨 갈 급수에 **자리가 남아 있을 때만** 처리됩니다. 자리가 없으면 버튼이 잠기고 안내가 표시됩니다. 현재 쓰던 자리는 옮기는 즉시 비므로, 가려는 급수만 비어 있으면 됩니다.
- 정정하면 **접수번호가 다시 부여됩니다.** (예: APP-21-1 → APP-21-2)
- 응시료가 다른데 이미 수납이 완료된 경우 **차액 안내가 표시**됩니다. 차액 정산은 자동으로 처리되지 않으니 현장에서 진행해 주시기 바랍니다.

**정정이 불가한 경우**

| 상황 | 조치 |
| --- | --- |
| 수험번호가 이미 부여됨 | 수험번호에 급수 구분이 포함되어 번호가 어긋납니다. **수험번호 부여 전에** 정정해 주십시오. |
| 토픽 Ⅰ·Ⅱ를 함께 접수 | 옮겨 갈 급수를 본인이 이미 사용 중입니다. 잘못 접수한 쪽을 **취소**해 주십시오. |
| 취소된 접수 | 아래 「접수 복원」을 먼저 진행해 주십시오. |
| 삭제(휴지통)된 접수 | 휴지통에서 **복구** 후 처리해 주십시오. |

## 3. 접수 복원 — 응시자가 '취소'를 잘못 누른 경우

**사용 방법**

1. 접수자 목록에서 상태가 **취소**인 건을 찾습니다. 상단 「취소」 버튼으로 걸러 보시면 편리합니다.
2. 맨 오른쪽 **「접수 복원」**을 누릅니다. (응시자 상세 화면의 「예외 처리」 칸에서도 가능합니다.)
3. 사유를 입력하고 복원합니다.

**참고 사항**

- **취소하기 직전 단계 그대로** 복원됩니다. 사진 심사가 완료되어 수납을 기다리던 상태였다면 그 상태로 돌아가며, 응시자는 마이페이지에서 이어서 진행합니다.
- 취소 시 자리가 반납되므로 **복원할 자리가 남아 있어야 합니다.** 그 사이 정원이 찬 경우에는 복원할 수 없습니다.

## 4. 지정 접수 — 한국 교민 자녀 등 특별 관리

**사용 방법**

1. 화면 오른쪽 위에서 **회차를 선택**합니다. (접수가 마감된 회차도 선택 가능합니다.)
2. 접수자 목록 위쪽 **「지정 접수」**를 누릅니다.
3. **이름·이메일·연락처로 회원을 검색**하여 선택합니다.
4. 시험장 · 응시 급수 · 사유를 입력하고 등록합니다.

**대상 조건**

대상은 **홈페이지 회원가입이 완료된 분**이어야 합니다. 증명사진·이름·생년월일 등이 연명부에 그대로 반영되기 때문입니다. 가입이 완료되지 않은 분과 정지·탈퇴 회원은 검색 결과에 표시되지 않으니, **먼저 가입을 완료하도록 안내**하신 뒤 등록해 주시기 바랍니다.

**참고 사항**

- 같은 회차에 이미 접수가 있는 경우 **동일한 시험장**이어야 합니다. (오전 Ⅰ·오후 Ⅱ가 다른 캠퍼스로 배정되면 응시자가 이동해야 하기 때문입니다.)
- 등록 후에는 **일반 접수와 동일하게** 사진 심사 → 수납 → 승인 → 수험번호 순서로 진행됩니다.
- 급수 옆에 회차·시험장 **남은 자리**가 표시되며, 자리가 없으면 등록되지 않습니다.
- 정원을 초과하여 등록해야 하는 경우 「정원이 가득 찼어도 등록」을 선택하십시오. **최고관리자만** 사용 가능하며, 이력에 「정원 초과 지정」으로 기록됩니다.

## 5. 특별 관리 명단 확인

- 접수자 목록 위쪽 **「지정 접수」**를 누르면 **지정 접수한 분들만** 모아 보실 수 있습니다.
- 명단의 상태 옆에 **「지정」** 표시가 붙으며, **이후 급수를 정정하더라도 이 표시는 유지**됩니다.
- **「예외 처리」**를 누르면 급수 정정·접수 복원·지정 접수 세 가지를 모두 확인하실 수 있습니다.
- 응시자 상세 화면의 「예외 처리」 칸에서 최근 처리 내용과 사유를, 「처리 이력」 탭에서 이전 처리 내역까지 확인 가능합니다.

## 6. 권한 설정

| 계정 | 사용 여부 | 설정 방법 |
| --- | --- | --- |
| 최고관리자 | 기본 사용 | 별도 설정 없이 세 기능을 모두 사용합니다. |
| 일반관리자 | 기본 잠김 | **관리자 권한 → 접수자 목록 → 「예외처리」** 체크 시 사용 가능합니다. |
| 조회 전용 | 사용 불가 | 권한을 부여하더라도 사용할 수 없습니다. |

「정원이 가득 찼어도 등록」은 권한 부여와 무관하게 **최고관리자 전용**입니다.

## 7. 운영 시 유의 사항

1. **급수 정정은 수험번호 부여 전에** 진행해 주십시오. 부여 후에는 번호 체계가 어긋나 정정할 수 없습니다.
2. **응시료 차액은 자동 정산되지 않습니다.** 화면 안내를 확인하시고 현장에서 처리해 주십시오.
3. **휴지통 관련** — 접수를 삭제한 뒤 동일한 분·동일 급수를 지정 접수로 다시 등록하면, 휴지통에 있던 건은 복구할 수 없습니다. 같은 급수가 두 건이 되는 것을 방지하기 위해 자동으로 차단됩니다. 남길 한 건을 정하신 뒤 처리해 주십시오.
4. 모든 예외 처리는 사유가 필수이며 입력하신 그대로 이력에 남습니다. 추후 확인이 가능하도록 구체적으로 작성해 주시기 바랍니다.
   - 예) 응시자 요청 — 토픽 Ⅰ·Ⅱ 혼동 접수 정정 (전화 확인 2026-08-19)
   - 예) 한국 교민 자녀 특별 관리 — 대사관 협조 공문 접수 (2026-08-19)

## 8. 기타

세 기능 모두 응시자에게 **별도 안내 메일이 발송되지 않습니다.** 기존 접수·취소와 동일한 방식이며, 응시자는 마이페이지에서 변경된 내용을 확인합니다. 메일 안내가 필요하신 경우 회신 주시면 반영하겠습니다.

기존 접수 데이터에는 영향이 없으며, 반영 후 서비스도 정상 동작을 확인하였습니다.

문의 사항 있으시면 언제든 연락 주십시오.
