bo 환불정보정정
- 답변을 분명 달았는데 로그아웃하고 들어오면 답변이 없음으로 나옴(fo에는 답변있음)
- 일반관리자도 분명 답변을 등록할수 있어야 하는데 등록할수 없음

fo 공지사항
- Bo 에 언어별로 제목, 본문 등록하였으나 fo 에서는 제목만 언어 전환이 되고 본문은 언어 전환이 안됨
- 이전글/다음글 노출이 안됨

bo 공지사항 노출시작, 노출종료
- 노출종료가 노출시작보다 과거 날짜이면 얼럿 메시지 또는 입력 안되게
- 노출시작, 노출종료 수정 후 저장 안됨

bo 로그인
- 관리자 계정 생성 후 해당 계정으로 첫 로그인 후 비밀번호 변경 완료하였는데 api 오류 발생
- 비밀번호 변경 완료되면 자동 로그아웃 후 관리자 로그인 페이지 리다이렉트하여 로그인 유도할수 있게 

bo 조회관리자
- 접수자 목록 조회만 가능, 상세보기 내 닫기 버튼 제외 모든 버튼 비활성화
- 회차관리 복제 버튼 비활성화

-------

bo 환불정보정정, 문의게시판
- 답변은 계속 달수 있으나 답변 이력이 fo, bo 둘다 쌓여서 히스토리가 다 보여야함
- 답변과 댓글/대댓글은 구분해서 노출
- 관리자에서도 대댓글 기능 활성화(지금은 댓글만 가능)

fo 공지사항
- 상세페이지에 조회수 삭제
